# Release Receipts

Receipts in this directory are generated, public-safe coordination metadata. They are secondary evidence only: they do not replace pinned source-owned repository evidence, grant publication authority, or certify a deployment.

Use `release-receipt.schema.json` for new receipts. Keep receipt text free of private paths, payloads, test detail, and unpublished work.

Historical receipt counts remain bound to their own observation and must not be rewritten when the public inventory changes. The validator requires the active candidate receipt to match the current registry and each final closure count to match its embedded immutable inventory observation.
